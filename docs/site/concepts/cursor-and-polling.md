# 커서와 폴링

워커는 활성 포스트를 나열한 뒤, 포스트마다 `after=` 커서로 새 메시지만 가져옵니다. 한 틱에 포스트당 최대 100개입니다.

커서는 항상 앞으로만 갑니다. 멘션 여부와 관계없이 읽은 메시지까지 `lastSeen`을 올립니다. 처리한 메시지만 커서를 옮기지 않습니다.

폴링 간격은 적응형입니다. 한가하면 긴 간격(기본 60초), 새 메시지가 있으면 짧은 간격(기본 10초)입니다. 값은 설정에서 읽습니다.

MVP 호스팅은 집 PC에서 `Forum.Cli` 스모크와 `Forum.Worker` 수동 실행까지입니다. 상시 가동은 후속입니다.
